# Chitall — рабочие правила

Это новый проект нативной iPhone-читалки для исследовательского чтения. Пользователь работает над исторической игрой и хочет превращать выделения из книг в материал для сюжета.

## Цель продукта

Сделать личное, спокойное, offline-first приложение: импортировать книгу, читать её, выделять фрагменты, добавлять мысль и теги, а затем экспортировать материал для совместной работы с ИИ.

## Способ работы

- Сначала изучи актуальные поддерживаемые варианты реализации и создай `DECISIONS.md` с аргументированными решениями.
- Не делай веб-приложение, React Native или Android-версию. Цель — нативный iPhone на SwiftUI; UIKit допустим внутри SwiftUI там, где это технически необходимо для нормального выделения текста.
- Не выбирай библиотеку или архитектуру по привычке: проверь актуальное состояние, лицензию, поддержку iOS и возможность сохранять точную позицию выделения.
- Не сокращай продукт до бессмысленного макета. Делай небольшой, но настоящий вертикальный срез: импорт → чтение → выделение → заметка/теги → просмотр заметок → экспорт.
- Работай итерациями. После каждого этапа запускай доступные тесты и обновляй краткий статус в `PROGRESS.md`.
- Не добывай книги из интернета, не обходи DRM и не включай чужие защищённые тексты в репозиторий. Пользователь импортирует только свои DRM-free файлы.
- Не требуй API-ключей, аккаунта или сервера для MVP. Данные должны храниться на устройстве.

## Файлы продукта

- `PRODUCT_BRIEF.md` — согласованная цель и MVP.
- `DECISIONS.md` — решения, альтернативы и причины.
- `PROGRESS.md` — сделанное, проверка и ближайший шаг.
- `docs/` — короткие технические заметки и схемы.

## Ограничение среды

Репозиторий может находиться на Windows, но сборка и установка нативного iPhone-приложения требуют macOS/Xcode. Если Xcode недоступен, всё равно создай корректный Xcode-проект и явно отдели непроверенные на устройстве места от реально проверенных.
