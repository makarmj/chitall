# Первый промпт для Claude Code

Скопируй текст ниже целиком в новый чат Claude Code, открытый в корне этого репозитория.

---

Прочитай `CLAUDE.md` и `PRODUCT_BRIEF.md`. Ты ведущий iOS-инженер и технический исследователь для нового приложения Chitall.

Не пиши приложение вслепую и не предлагай упрощённую веб-версию. Сначала самостоятельно исследуй актуальные поддерживаемые подходы к реализации нативной iPhone-читалки DRM-free FB2 на SwiftUI. Нам критично, чтобы пользователь мог выделять текст, а приложение сохраняло не только фрагмент, но и устойчивую точную позицию внутри исходного файла.

Дай себе пространство для профессионального решения: если требования брифа конфликтуют с реальными ограничениями iOS или FB2, объясни конфликт и предложи лучший вариант, сохраняя главную цель продукта. Сравни минимум два реалистичных подхода к рендерингу и выделению текста, проверь лицензии зависимостей и выбери один. Не подключай тяжёлую или мёртвую зависимость без причины.

Затем:
1. Создай `DECISIONS.md`: варианты, решение, компромиссы, план добавления EPUB на втором этапе.
2. Создай `PROGRESS.md` с начальным этапом и критериями готовности.
3. Составь небольшой план реализации MVP с проверяемыми этапами.
4. После того как план и решения записаны, создай реальный Xcode-проект iOS 17+ и реализуй первый рабочий вертикальный срез: импорт FB2 → библиотека → открытие книги → выделение текста → заметка и теги → локальное сохранение → экспорт Markdown/JSON.
5. Добавь тесты для парсинга FB2, стабильности locator-а и генерации экспорта.
6. Не останавливайся на мокапах. Если среда не позволяет запустить Xcode, всё равно подготовь проект, выполни доступные статические проверки и точно зафиксируй, что требует проверки на macOS.

После каждой завершённой стадии кратко обновляй `PROGRESS.md`. В финале дай список созданных файлов, результаты проверок и только реальные ограничения.
