# Проверка на macOS

Здесь собрано всё, что нельзя проверить на Windows. Проект написан вручную, без Xcode, поэтому первая сборка на Mac и есть первая настоящая проверка UI-слоя.

## 1. Открыть и собрать

1. Нужен Xcode 16 или новее (проект в формате buildable folders, `objectVersion = 77`); проверялось бы на Xcode 27.
2. Открыть `Chitall.xcodeproj`. Xcode сам подтянет локальный пакет `ChitallCore`.
3. Target **Chitall** → Signing & Capabilities: выбрать свою команду. Если `com.chitall.reader` занят, заменить Bundle Identifier (и у `ChitallTests` тоже).
4. Собрать на симуляторе iPhone (iOS 17 и последней версии) и на устройстве.
5. `⌘U` — запускает `ChitallTests` (приложение) и `ChitallCoreTests` (пакет).
6. В терминале: `swift test --package-path ChitallCore` — на macOS это дополнительно проверяет ветки, недоступные на Windows: SHA-256 через CryptoKit и распаковку deflate через `Compression`.

Если проект не открывается (ошибка разбора `project.pbxproj`):
1. File → New → Project → iOS App, имя `Chitall`, интерфейс SwiftUI, хранилище None, тесты включены; сохранить во временную папку.
2. Удалить сгенерированные исходники, перетащить папки `Chitall/` и `ChitallTests/` в навигатор как папки (не группы) в соответствующие таргеты.
3. File → Add Package Dependencies → Add Local… → папка `ChitallCore`; продукт `ChitallCore` — в таргет приложения.
4. Build Settings приложения: `INFOPLIST_FILE = Config/Info.plist`, `IPHONEOS_DEPLOYMENT_TARGET = 17.0`, `SWIFT_VERSION = 5`.

## 2. Ручной чек-лист на устройстве

Импорт и библиотека
- [ ] «Открыть пробную книгу» в пустой библиотеке — книга открывается.
- [ ] Импорт `.fb2` из «Файлов» (в том числе из iCloud Drive) — книга в библиотеке с названием, автором, обложкой или заглушкой.
- [ ] Импорт `.fb2.zip`.
- [ ] Импорт `windows-1251` FB2 — кириллица без «кракозябр».
- [ ] Повторный импорт того же файла — «Уже в библиотеке», дубля нет.
- [ ] Пустой файл, обрезанный FB2, HTML, zip без FB2 — понятная ошибка на русском.
- [ ] «Поделиться → Chitall» из «Файлов» импортирует книгу.

Чтение
- [ ] Главы, оглавление (включая вложенные разделы), переходы «‹ ›».
- [ ] Размер шрифта и интервал меняются, позиция в главе не прыгает.
- [ ] Темы «Бумага», «Дерево», «Как в системе», включая уже открытую книгу.
- [ ] Тап по сноске `[1]` показывает примечание; долгое нажатие не открывает браузер.
- [ ] Поиск по главе (лупа) — системная панель «Найти».
- [ ] Закрыть книгу на середине главы, открыть снова — та же строка вверху. То же после принудительного закрытия приложения.

Выделения
- [ ] Системное выделение: ручки, лупа, выделение через несколько абзацев и через пустую строку.
- [ ] В меню: «Выделить» → пять цветов, «Мысль…», системные «Скопировать», «Найти в словаре», «Перевести».
- [ ] Цвет появляется сразу, выделение снимается.
- [ ] «Мысль…» открывает редактор: цвет, текст мысли, теги, новый тег, источник (книга, глава, locator, даты).
- [ ] Тап по подсветке открывает редактор; у подсветки с мыслью — пунктирное подчёркивание.
- [ ] Удаление выделения из редактора; подсветка исчезает.
- [ ] Выделения на месте после перезапуска приложения.

Материалы и экспорт
- [ ] Поиск по цитате/мысли, `#тайна` в поиске, фильтры «Книга», «Тег», цвет, «Сбросить».
- [ ] «Открыть в книге» — книга открывается на этом месте.
- [ ] Экспорт → «Поделиться Markdown и JSON» → «Сохранить в Файлы»; оба файла открываются, в них только выбранные выделения.
- [ ] Удаление книги: диалог называет число выделений; «оставить материалы» — выделения остаются в «Материалах», без кнопки «Открыть в книге»; повторный импорт того же файла снова их связывает.

## 3. Места повышенного риска

Это места, где код опирается на поведение iOS, которое без устройства не проверить:

| Место | Что может пойти не так | Что делать |
|---|---|---|
| Меню выделения в нередактируемом `UITextView` | Набор системных пунктов отличается между версиями iOS | Свои пункты не зависят от системных; при проблеме отфильтровать `suggestedActions` |
| Тап по тексту | Небольшая задержка одиночного тапа (ждём отказа двойного) | Ожидаемо; при раздражающей задержке перенести переключение панели на отдельную зону |
| TextKit 1 и очень длинная глава (сотни тысяч символов) | Заметная пауза при открытии главы | Включить `allowsNonContiguousLayout` и `ensureLayout` диапазона вместо всего контейнера |
| Удаление выделения из карточки в «Материалах» | Обращение к удалённой SwiftData-модели во время анимации возврата | Сделано отложенное удаление; проверить, что нет падения |
| `@Query` и изменения цвета/заметки | Подсветка обновляется не сразу | Обновление идёт через Observation чтением `colorKey`/`note` в `body` |
| Импорт из iCloud Drive | Файл не скачан на устройство | Используется `NSFileCoordinator`, проверить на нескачанном файле |
