# Читалки-конкуренты и что из этого следует для Chitall

Обзор на 2026-10-11 по открытым источникам (App Store, обзоры, документация). Цель — понять, где Chitall должен быть не хуже других, а где может быть заметно лучше.

## Кто есть на рынке

| Приложение | Форматы | Чтение | Заметки и экспорт | Особенности |
|---|---|---|---|---|
| **Apple Books** | EPUB, PDF | Страницы и прокрутка, сильная типографика | Выделения и заметки; внешнего экспорта нет | Встроено в iOS, iCloud; FB2 не открывает |
| **Kindle** | Свои форматы; EPUB через Send to Kindle | Страницы, Word Wise, X-Ray | Заметки внутри экосистемы Amazon | Закрытая экосистема с DRM, слабая работа со своими файлами |
| **KyBook 3** | EPUB, FB2/FB2.ZIP, PDF, DjVu, MOBI | Перелистывание сдвигом, «скручиванием» и прокруткой | Выделения, закладки, рисование; экспорт аннотаций в Markdown, HTML, PDF, RTF | Очень много настроек, OPDS, TTS; обновляется редко, порог входа высокий |

## Что обязательно для «нормальной» читалки (база)

1. **Страницы с тапами по краям и свайпом**, прокрутка — как опция. ← сделано в итерации 2.
2. **Поиск по всей книге** со списком результатов. ← сделано в итерации 2.
3. Типографика: шрифт (2–4 гарнитуры), размер, интервал, **поля**, выравнивание по ширине с **переносами**.
4. Темы: светлая, сепия, тёмная, «как в системе»; яркость/тёплый фильтр.
5. Оглавление, **закладки**, прогресс «осталось в главе / в книге», время до конца главы.
6. **EPUB** (основной формат легальных DRM-free книг), затем TXT, PDF.
7. Библиотека: серии, коллекции/полки, сортировка, поиск по библиотеке.
8. Словарь и перевод выделенного (у нас уже есть системные «Найти в словаре» и «Перевести»).

## Где Chitall может быть лучше всех

Конкуренты — читалки с заметками на полях. Chitall — инструмент исследователя, который превращает чтение в материал для истории:

- **Точное происхождение каждой цитаты.** Locator v1 переживает переформатирование и смену кодировки, переякоривается после правки файла. Так не умеет никто из списка.
- **Мысль и теги как первоклассные данные.** Тег-словарь для сюжета (`#место #свет #звук #кадр…`), фильтры, поиск по `#тегу`.
- **Экспорт для работы с ИИ.** Markdown для чата и JSON со стабильной схемой; в экспорт попадает только выбранное, без текста книги вокруг.
- **Приватность и офлайн.** Ни аккаунта, ни сети, ни аналитики.

Следующие шаги, которые усиливают именно это отличие:
1. **Проекты/доски:** выделения из разных книг собираются в «проект игры» с порядком и группами (сцены, персонажи, локации).
2. **Карточка сцены:** из нескольких выделений и мыслей собирается черновик сцены; экспорт проекта целиком.
3. **Шаблоны экспорта** (как у Readwise): Markdown для Obsidian, промпт-пакет для ИИ, CSV.
4. **Связи между материалами:** «похоже на…», ссылки между выделениями, таймлайн по книгам.
5. Опционально и только по явному выбору — **ИИ-помощник** на устройстве или по ключу пользователя: «объясни реалию эпохи», «предложи сцену из выбранных выделений».

## Публикация в App Store

Нужно: Apple Developer Program (99 $/год), политика конфиденциальности (у нас «данные не собираются» — короткая), описание и скриншоты, ответы на вопросы о шифровании (уже `ITSAppUsesNonExemptEncryption = NO`), Privacy manifest (уже есть). Ограничения App Review для читалок: приложение не должно помогать получать пиратские книги и обходить DRM — Chitall только открывает собственные файлы пользователя, магазина и каталогов в нём нет. Распространённая практика FB2-читалок в App Store это подтверждает (KyBook, FBReader).
