# План реализации MVP

Вертикальный срез: импорт FB2 → библиотека → открытие → выделение → заметка и теги → локальное сохранение → экспорт Markdown/JSON.
Каждый этап заканчивается проверкой; «проверено» пишется только про то, что реально запускалось. Статус на 2026-10-11.

| # | Этап | Результат | Как проверяется | Статус |
|---|---|---|---|---|
| 0 | Исследование и решения | `DECISIONS.md`, этот план, `PROGRESS.md` | Ревью документов | готово |
| 1 | Ядро: кодировки и разбор FB2 | `ChitallCore`: определение кодировки, табличные декодеры, `FB2Parser` → модель книги, понятные ошибки | `swift test` (Windows): UTF-8/16, 1251, KOI8-R, вложенные секции, стихи, сноски, обложка, битые файлы | готово, проверено |
| 2 | Ядро: текст главы и locator | `ChapterText` (плоский текст + карта блоков UTF-16), `Locator` v1, канонизация, создание/разрешение/переякоривание | `swift test`: round-trip, переформатирование XML, смена кодировки, вставка абзаца, кодовые точки vs UTF-16 | готово, проверено |
| 3 | Ядро: экспорт, теги, фильтр | `MarkdownExporter`, `JSONExporter`, `TagNames`, `MaterialFilter` | `swift test`: эталонный Markdown, структура JSON, отсутствие контекста книги в экспорте | готово, проверено |
| 4 | ZIP-контейнер | `.fb2.zip`: stored в ядре, deflate через `Compression` на Apple | `swift test`: stored, повреждённый архив, CRC, архив без FB2; deflate — на macOS | готово; deflate не проверен |
| 5 | Xcode-проект и оболочка приложения | `Chitall.xcodeproj`, SwiftData-схема, библиотека, импорт, ошибки, удаление с подтверждением | `tools/check_project.py`, `swiftc -parse`; сборка — на macOS | написано; сборка не проверена |
| 6 | Читалка | `UITextView` (TextKit 1), главы и оглавление, шрифт, интервал, темы, позиция, сноски, поиск | Чек-лист на устройстве | написано; не проверено |
| 7 | Выделения | Меню выделения с цветами, «Мысль…», редактор, теги, тап по подсветке | `ChitallTests` + чек-лист | написано; не проверено |
| 8 | «Материалы» и экспорт | Поиск, фильтры, карточка, «Открыть в книге», Share Sheet | Экспорт — `swift test`; UI — чек-лист | написано; UI не проверен |
| 9 | Сводная проверка | `PROGRESS.md`, `docs/macos-checklist.md` | Все доступные проверки зелёные | готово |

Критерии готовности MVP — в [PROGRESS.md](../PROGRESS.md).
