# Как поставить Chitall на свой iPhone с чужого Мака

Собрать iOS-приложение можно только на Mac в Xcode. Платный аккаунт разработчика не нужен: хватает обычного Apple ID.

## 0. Что проверить заранее

| Что | Требование | Где посмотреть |
|---|---|---|
| iPhone | iOS 17 или новее | Настройки → Основные → Об этом устройстве |
| Мак | macOS, на которую ставится Xcode 16 или новее (Xcode 16 — от macOS 14.5; Xcode 26 — от macOS 15.6; Xcode 27 — от macOS 26.6 и только Apple silicon) | Меню  → Об этом Mac |
| Xcode | Не старше версии iOS на телефоне: для iPhone на iOS 26 нужен Xcode 26+, на iOS 27 — Xcode 27+ | App Store → Xcode (≈ 10–15 ГБ, качается долго) |
| Кабель | Для первого подключения iPhone к Маку | USB-C или Lightning |
| Apple ID | Ваш (можно и друга, но тогда приложение будет подписано его аккаунтом) | — |

## 1. Получить проект

Проект лежит в приватном репозитории https://github.com/makarmj/chitall.

1. Владелец репозитория: github.com → репозиторий → Settings → Collaborators → Add people → GitHub-логин друга. Друг принимает приглашение (придёт на почту).
2. На Маке в «Терминале»:
   ```bash
   git clone https://github.com/makarmj/chitall.git ~/Documents/chitall
   ```
   При первом обращении macOS предложит установить Command Line Tools, если их нет, — соглашайтесь. Если git попросит войти, удобнее всего через GitHub Desktop или `gh auth login`.
3. Потом, чтобы получить новые исправления: `cd ~/Documents/chitall && git pull`. Настройки подписи (шаг 2) меняют `project.pbxproj`; если `git pull` откажется из-за локальных изменений, выполните `git stash && git pull && git stash pop` — подпись сохранится. Новые файлы кода `project.pbxproj` не трогают (папки синхронизируются сами), так что конфликты редки.

Без git: на странице репозитория Code → Download ZIP, распаковать.

Перед походом к другу загляните во вкладку **Actions** репозитория: зелёная галочка у последней сборки значит, что проект собирается на Маке и тесты проходят.

## 2. Открыть и подписать

1. Двойной щелчок по `Chitall.xcodeproj` → откроется Xcode. Подождите, пока внизу закончится «Resolving packages» / индексирование.
2. Xcode → Settings → Accounts → «+» → Apple ID → войти.
3. Слева синий значок проекта **Chitall** → таргет **Chitall** → вкладка **Signing & Capabilities**:
   - галочка **Automatically manage signing**;
   - **Team**: «Ваше имя (Personal Team)»;
   - **Bundle Identifier**: замените `com.chitall.reader` на уникальный, например `com.ivanov.chitall` (латиница, без пробелов). Иначе Xcode скажет, что идентификатор занят.
4. То же для таргета **ChitallTests**: Team — тот же, Bundle Identifier — `com.ivanov.chitallTests`.

## 3. Подключить iPhone

1. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять этому компьютеру».
2. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить → телефон перезагрузится → подтвердить. (Пункт появляется после первого подключения к Xcode.)
3. В Xcode вверху в списке устройств выберите свой iPhone.

## 4. Собрать и запустить

1. Нажмите ▶︎ (или ⌘R).
2. Если на iPhone появилось «Ненадёжный разработчик»: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять». Потом снова ▶︎.
3. Если сборка остановилась с ошибками (красные значки), откройте вкладку ошибок (⌘5), скопируйте **текст всех ошибок** и пришлите в чат с Claude. Код интерфейса впервые собирается на Mac, мелкие ошибки компиляции возможны.

## 5. Важно про бесплатную подпись

- Приложение с бесплатного Apple ID **работает 7 дней**, потом перестаёт открываться. Чтобы продлить, снова подключите iPhone к Маку и нажмите ▶︎. **Данные при этом сохраняются.**
- **Не удаляйте приложение с телефона**: вместе с ним удалятся книги и выделения. Время от времени делайте экспорт в «Материалах» и сохраняйте файлы в «Файлы».
- Бесплатно можно держать до 3 таких приложений на одном устройстве.
- Без 7-дневного ограничения: Apple Developer Program (99 $ в год) — подпись на год и TestFlight. Мак всё равно нужен для сборки, но реже.

## 6. Проверка после установки

Пройдите короткий список в [macos-checklist.md](macos-checklist.md), раздел 2: пробная книга, импорт своего FB2, выделение, мысль и теги, «Материалы», экспорт.
