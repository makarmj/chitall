# Формат экспорта

Экспорт создаёт два файла с одинаковым именем: `chitall-materials-YYYYMMDD-HHmm.md` и `.json`. В них только выбранные пользователем выделения (вся выборка «Материалов» с текущими поиском и фильтрами). Ни полного текста книги, ни контекста вокруг цитат в экспорте нет.

Реализация: `ChitallCore/Sources/ChitallCore/Export/`, тесты: `ExportTests`.

## Markdown

Для человека и для вставки в чат с ИИ. Порядок: книги по названию, внутри книги — по месту в тексте, заголовок главы перед первой цитатой из неё.

```markdown
# Материалы Chitall

- Экспорт: 2026-10-11 17:00 (GMT+0300)
- Выборка: все материалы
- Выделений: 2, книг: 1

---

## Соляной обоз

*Анна Тестова*

### Глава вторая

> Один мешок оказался легче остальных.

**Мысль.** Кто-то отсыпал соль по дороге?

- Теги: #тайна #предмет
- Цвет: киноварь
- Создано: 2026-10-11 15:10
- Место: `fb2 sha256:3b05d718 /FictionBook/body[1]/section[2]/p[2]:0–36`, 80,0 % книги
```

Строки цитат и заметок, начинающиеся с `#`, `>`, `-`, `+`, `*`, `=`, `|` или `1.`, экранируются обратной косой чертой, чтобы не превратиться в разметку. Даты — в часовом поясе устройства, без зависимости от локали.

## JSON, схема `chitall.export` v1

Ключи отсортированы, даты — ISO 8601 UTC, кодировка UTF-8, в конце перевод строки.

```json
{
  "books": [{ "authors": "Анна Тестова", "id": "sha256:…", "title": "Соляной обоз" }],
  "exportedAt": "2026-10-11T14:00:00Z",
  "generator": "Chitall 0.1 (1)",
  "highlights": [
    {
      "book": "sha256:…",
      "chapter": { "index": 2, "title": "Глава вторая" },
      "color": { "key": "cinnabar", "name": "киноварь" },
      "createdAt": "2026-10-11T12:10:00Z",
      "id": "B0000000-0000-0000-0000-000000000002",
      "locator": {
        "book": "sha256:…", "chapter": 2, "format": "fb2", "progression": 0.8, "v": 1,
        "start": { "offset": 0, "path": "/FictionBook/body[1]/section[2]/p[2]" },
        "end": { "offset": 36, "path": "/FictionBook/body[1]/section[2]/p[2]" }
      },
      "note": "Кто-то отсыпал соль по дороге?",
      "tags": ["тайна", "предмет"],
      "text": "Один мешок оказался легче остальных.",
      "updatedAt": "2026-10-11T12:30:00Z"
    }
  ],
  "schema": "chitall.export",
  "selection": { "bookCount": 1, "description": "все материалы", "highlightCount": 1 },
  "version": 1
}
```

| Поле | Смысл |
|---|---|
| `books[].id` | Отпечаток файла книги, на него ссылаются `highlights[].book` и `locator.book`. |
| `highlights[].text` | Ровно выделенный текст, абзацы через `\n`. |
| `highlights[].tags` | Имена тегов без `#`, в нижнем регистре, пробелы → `_`. |
| `highlights[].color.key` | `ochre`, `olive`, `azure`, `cinnabar`, `lilac`. |
| `highlights[].locator` | Locator v1 без `quote` (см. [locator.md](locator.md)). |

Добавление полей не меняет `version`; переименование или удаление — меняет.
