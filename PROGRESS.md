**Команды:** `pwsh tools/test-core.ps1` — тесты ядра на Windows; `python -I tools/check_project.py` — проверка проекта; `swiftc -parse` по `Chitall/` — синтаксис приложения; сборка и тесты приложения — только в CI (`gh run list`, `gh run view --log`), документы CI не запускают.

## Журнал

### Этап 0 — исследование (2026-10-11)
- Сравнены: `UITextView`/TextKit 1 и 2, `WKWebView` + Readium Swift Toolkit (BSD-3, 3.11.0 / 4.0-alpha, без FB2), SwiftUI `Text`/`TextEditor` (iOS 26–27, нет API диапазона под iOS 17), свой Core Text; SwiftData / Core Data / GRDB; `XMLParser` / `XMLDocument` (нет на iOS); формат проекта Xcode 16+. Выбор и причины — в `DECISIONS.md`.
- Среда: Windows, Xcode недоступен. С разрешения пользователя установлен Swift 6.4.0 для Windows (winget, swift.org), чтобы реально собирать и тестировать ядро.

### Этапы 1–4 — ядро `ChitallCore`
- Кодировки (BOM, пролог, табличные windows-1251/koi8-r/cp866/windows-1252, latin-1, UTF-16; эвристика для неверно объявленных файлов), XML-дерево на `XMLParser`, FB2 → `ReadableBook` (главы, оглавление, стихи, цитаты, эпиграфы, таблицы, картинки, сноски, обложка), `ChapterText`, `Locator` v1 + `LocatorService`, экспорт, теги, фильтр, ZIP, SHA-256.
- Проверка: 78 тестов на Windows, включая разбор пробной книги, которая поставляется с приложением.

### Этапы 5–8 — приложение
- `Chitall.xcodeproj` (buildable folders, локальный пакет, общая схема с тестами приложения и пакета), Info.plist с типом FB2, Privacy manifest, иконка, пробная книга (собственный текст).
- SwiftData-схема v1 без связей; хранение исходных байтов книги; импорт с security scope и `NSFileCoordinator`; библиотека с удалением; читалка на `UITextView` (TextKit 1) с меню выделения, подсветками, сносками, оглавлением, поиском, настройками и восстановлением позиции; редактор выделения; «Материалы» с поиском и фильтрами; экспорт через `ShareLink`; настройки и список тегов.
- Проверка: `check_project.py` OK, `swiftc -parse` OK.

### CI на GitHub (2026-10-11)
- Установлены Git 2.55 и GitHub CLI 2.102, проект загружен в приватный репозиторий `makarmj/chitall`, добавлен workflow `.github/workflows/build.yml` (macOS runner).
- Первый же прогон зелёный: приложение компилируется в Xcode 26.6, 8 тестов приложения на симуляторе iOS 26.5 и 78 тестов ядра на macOS проходят. Лог проверен вручную: тесты действительно выполнялись.
- Уточнение: `⌘U` запускает только тесты приложения; ссылку на тесты пакета в схеме Xcode игнорировал — убрана, тесты ядра идут через `swift test`.

### Первая проверка на iPhone (2026-10-11)
- Установлено с Мака друга через Xcode (бесплатная подпись Apple ID).
- Работает на устройстве: пробная книга, чтение, тёмная тема «Дерево», выделение с мыслью и тегами `#место #свет`, экспорт Markdown через «Поделиться» (файл проверен: цитата, мысль, теги, цвет, дата, locator, часовой пояс Europe/Minsk).
- Найдено: системный поиск показывал совпадение под клавиатурой.
- Пожелания: страницы с перелистыванием тапом по краям или сквозная прокрутка всей книги; больше форматов; изучить конкурентов; возможная публикация.

### Итерация 2 — страницы и поиск по книге
- Режим «Страницы» (по умолчанию): разметка TextKit 1 по контейнерам-страницам, отдельный `UITextView` на страницу, `UIPageViewController`, тап по краям и свайп, сквозной переход через главы, позиция = первый символ страницы, переразметка при смене шрифта и поворота. Режим «Прокрутка» остаётся в настройках.
- Поиск по всей книге (ядро `BookSearch`) со списком результатов вместо системной панели «Найти».
- Обзор конкурентов: [docs/competitors.md](docs/competitors.md); решение: DECISIONS.md §15.
- Проверка (реально выполнено): тесты ядра на Windows — 85, 0 падений; `swiftc -parse` — 24 файла; **CI на macOS (Xcode 26.6, симулятор iPhone 17 Pro, iOS 26.5): сборка без предупреждений в нашем коде, 14 тестов приложения и 85 тестов ядра — 0 падений.** Новые тесты: страницы покрывают каждый символ ровно один раз, каждая страница помещается в свою область, крупный шрифт даёт больше страниц и смещения находят свою страницу, перенесённый абзац без красной строки, иллюстрация выше страницы не ломает разметку, поиск переходит к главе и подчёркивает совпадение.
- Не проверено: живое поведение на iPhone — тапы по краям, свайп, выделение на странице, переход через главу, поворот экрана. Обновление ставится по [docs/codex-update.md](docs/codex-update.md).

### Вторая проверка на iPhone и итерация 2.1 (2026-10-11)
- На устройстве: поиск по книге работает хорошо, выделение — без замечаний.
- Замечания: прокрутка шла только в пределах главы; тапы у края страницы срабатывали через раз.
- Сделано: прокрутка всей книги одной лентой (DECISIONS.md §16); тап по всей площади страницы, мгновенный у краёв, очередь тапов во время анимации; подсказка с зонами при первом открытии.
- Проверка (реально выполнено, CI на macOS, коммит `c5d45e5`): сборка без предупреждений в нашем коде; 16 тестов приложения и 85 тестов ядра — 0 падений. Новые тесты: куски главы для ленты покрывают текст и не дают пустых строк на стыках; при открытии главы предыдущая подгружается сверху, а читатель остаётся на первой строке своей главы; при прокрутке вниз главы подгружаются по порядку до конца книги. ## Известные ограничения MVP

- Подсветки прямоугольные.
- Выделение не переходит через границу страницы (в режиме страниц) — как в большинстве читалок; длинную цитату можно выделить в режиме прокрутки.
- В режиме прокрутки выделение не переходит через границу куска (≈1,5 экрана).
- Встроенные в абзац картинки не показываются (блочные иллюстрации и обложка — показываются).
- Перенесённые (переякоренные) выделения не перезаписывают свой locator — пересчитываются при каждом открытии.
- Один общий набор «Материалов», без отдельных проектов (теги закрывают эту потребность в MVP).
