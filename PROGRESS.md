## Критерии готовности MVP

Статус: ✅ проверено тестами здесь · 📝 код написан, проверка на Mac · ⬜ не сделано.

- 📝 Импорт DRM-free `.fb2`/`.fb2.zip` через Files picker и «Открыть в Chitall»; книга в библиотеке с обложкой или заглушкой, названием, автором, датой последнего чтения. (✅ разбор, zip stored, отпечаток.)
- ✅ Пустой, битый, не-FB2, неподдерживаемый файл → понятная ошибка на русском (ядро); 📝 показ в UI.
- 📝 Чтение по главам; размер шрифта, интервал, «Бумага»/«Дерево»/системная тема, запоминание.
- 📝 Системное выделение; меню «Выделить» (5 цветов), «Мысль…», «Открыть выделение» + системные пункты.
- 📝 Цвет, мысль, произвольные теги; встроенные `#место #свет #звук #предмет #персонаж #тайна #конфликт #реплика #кадр` и свои. (✅ нормализация тегов.)
- ✅ Происхождение: SHA-256 книги, название книги и главы, locator v1 (путь + смещения в кодовых точках + цитата), текст, даты — модель и тесты; 📝 сохранение в SwiftData.
- 📝 Выделения и позиция чтения переживают перезапуск (тест `testHighlightSurvivesContainerRestart` написан, запуск — в Xcode). ✅ Locator переживает переразбор, переформатирование, перекодировку и переякоривается после правки файла.
- 📝 «Материалы»: поиск, фильтры по книге, тегу, цвету, `#тег` в поиске, «Открыть в книге». (✅ логика фильтра.)
- ✅ Экспорт Markdown и JSON: эталонный Markdown, структура JSON, в экспорте нет контекста книги; 📝 Share Sheet.

## Журнал

### Этап 0 — исследование (2026-10-11)
- Сравнены: `UITextView`/TextKit 1 и 2, `WKWebView` + Readium Swift Toolkit (BSD-3, 3.11.0 / 4.0-alpha, без FB2), SwiftUI `Text`/`TextEditor` (iOS 26–27, нет API диапазона под iOS 17), свой Core Text; SwiftData / Core Data / GRDB; `XMLParser` / `XMLDocument` (нет на iOS); формат проекта Xcode 16+. Выбор и причины — в `DECISIONS.md`.
- Среда: Windows, Xcode недоступен. С разрешения пользователя установлен Swift 6.4.0 для Windows (winget, swift.org), чтобы реально собирать и тестировать ядро.

### Этапы 1–4 — ядро `ChitallCore`
- Кодировки (BOM, пролог, табличные windows-1251/koi8-r/cp866/windows-1252, latin-1, UTF-16; эвристика для неверно объявленных файлов), XML-дерево на `XMLParser`, FB2 → `ReadableBook` (главы, оглавление, стихи, цитаты, эпиграфы, таблицы, картинки, сноски, обложка), `ChapterText`, `Locator` v1 + `LocatorService`, экспорт, теги, фильтр, ZIP, SHA-256.
- Проверка: 78 тестов на Windows, включая разбор пробной книги, которая поставляется с приложением.

### Этапы 5–8 — приложение
- `Chitall.xcodeproj` (buildable folders, локальный пакет, общая схема с тестами приложения и пакета), Info.plist с типом FB2, Privacy manifest, иконка, пробная книга (собственный текст).
- SwiftData-схема v1 без связей; хранение исходных байтов книги; импорт с security scope и `NSFileCoordinator`; библиотека с удалением; читалка на `UITextView` (TextKit 1) с меню выделения, подсветками, сносками, оглавлением, поиском, настройками и восстановлением позиции; редактор выделения; «Материалы» с поиском и фильтрами; экспорт через `ShareLink`; настройки и список тегов.
- Проверка: `check_project.py` OK, `swiftc -parse` OK. Компиляция и запуск — не выполнялись (нужен Mac).

## Известные ограничения MVP

- Подсветки прямоугольные; нет постраничного режима.
- Встроенные в абзац картинки не показываются (блочные иллюстрации и обложка — показываются).
- Поиск — внутри главы (системный «Найти»); поиск по всей книге не сделан.
- Перенесённые (переякоренные) выделения не перезаписывают свой locator — пересчитываются при каждом открытии.
- Один общий набор «Материалов», без отдельных проектов (теги закрывают эту потребность в MVP).
