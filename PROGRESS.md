**Отзыв с телефона по итерации 3 (2026-10-12) — пункты 1–4 исправлены в итерации 3.1 (см. журнал):**
1. **Баг:** в панели «Оформление» на тёмных темах («Чёрный», «Дерево», «Как в системе» при тёмной системе) не видны подписи и значки: названия шрифтов, значки интервала и полей, «По ширине, с переносами», подсказка внизу — тёмный текст на тёмном фоне. Видны только кнопки тем и размер −/+.
2. **Сноски как в Яндекс Книгах:** тап по номеру сноски (у них — `[23]` с пунктирным подчёркиванием) открывает снизу карточку с текстом сноски, без перехода в конец книги. Проверить на книге со сносками.

3. **Процент по книге** под ползунком («36,5 % · Gloria victis») — без десятых: целое число, 100 % — только в самом конце.
4. **Закладки не работают в режиме «Прокрутка»** (в «Страницах» работают). Хочется как в Яндекс Книгах: лента делится на участки; на участке можно поставить закладку; при прокрутке дальше значок закладки становится пустым, при возврате — снова заполненным, так находишь, где читал. Можно лучше (пользователь будет рад), например: отметка закладки на полях ленты и в ползунке.
5. Хорошо: тапы по краям, быстрый тег («классно придумал»). Шрифты, темы и номера страниц — замечаний нет, кроме п. 1.

### Этап 0 — исследование (2026-10-11)
- Сравнены: `UITextView`/TextKit 1 и 2, `WKWebView` + Readium Swift Toolkit (BSD-3, 3.11.0 / 4.0-alpha, без FB2), SwiftUI `Text`/`TextEditor` (iOS 26–27, нет API диапазона под iOS 17), свой Core Text; SwiftData / Core Data / GRDB; `XMLParser` / `XMLDocument` (нет на iOS); формат проекта Xcode 16+. Выбор и причины — в `DECISIONS.md`.

## Известные ограничения MVP

- Подсветки прямоугольные.
- Выделение не переходит через границу страницы (в режиме страниц) — как в большинстве читалок; длинную цитату можно выделить в режиме прокрутки.
- В режиме прокрутки выделение не переходит через границу куска (≈1,5 экрана).
- Встроенные в абзац картинки не показываются (блочные иллюстрации и обложка — показываются).
- EPUB: оформление CSS-классами (например, `<span class="italic">`), таблицы сеткой, fixed-layout, SVG-картинки, аудио/видео не поддерживаются; очень большой XHTML-файл — одна глава.
- Перенесённые (переякоренные) выделения не перезаписывают свой locator — пересчитываются при каждом открытии.
- Один общий набор «Материалов», без отдельных проектов (теги закрывают эту потребность в MVP).
