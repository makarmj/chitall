# Chitall — продуктовый бриф v0.1

## Одно предложение

Личная iPhone-читалка для исследовательского чтения, которая превращает выделения и мысли читателя в структурированный экспорт для разработки истории.

## Для кого

Для одного автора, который читает исторические и художественные книги, собирает атмосферу, детали мира, конфликты и сюжетные идеи для будущей игры.

## Сценарий успеха

1. Пользователь переносит свой DRM-free FB2-файл в приложение через системный Files picker.
2. Открывает книгу и читает её в удобном светлом или тёмном режиме.
3. Выделяет важный фрагмент, выбирает цвет, добавляет свою мысль и теги.
4. Позже открывает все заметки проекта, фильтрует их, например, по `#тайна` или `#кадр`.
5. Экспортирует проект в Markdown и JSON через системное меню «Поделиться» и прикладывает файл в чат с ИИ.

## Формат первой версии: FB2

Начать с FB2 — осознанное решение для быстрого первого вертикального среза. FB2 — XML, поэтому можно разобрать структуру локально и сохранить устойчивый locator: идентификатор книги + путь XML-узла/главы + символьный диапазон выделения. Это важнее, чем поддержка сотни форматов.

EPUB не запрещён навсегда, но это второй этап. Claude должен зафиксировать, какой интерфейс абстракции чтения позволит добавить EPUB без переписывания модели книг, выделений и экспорта.

## Необходимое в MVP

- iOS 17+; нативный SwiftUI.
- Импорт DRM-free FB2 через Files picker.
- Локальная библиотека: обложка-заглушка, название, автор, дата последнего чтения.
- Чтение одной главы/длинного текста с регулируемыми размером шрифта, межстрочным интервалом, светлой и тёмной темой.
- Нормальное системное выделение текста.
- Цветные выделения.
- Заметка и произвольные теги у каждого выделения.
- Точные данные происхождения: книга, название главы, locator, выделенный текст, дата.
- Экран «Материалы»: поиск, фильтр по книге, тегу и цвету.
- Экспорт проекта в читаемые Markdown и JSON-файлы через Share Sheet.
- Local-first: SwiftData или иной Apple-native persistence; без аккаунта, аналитики и сети.

## Важные теги по умолчанию

`#место`, `#свет`, `#звук`, `#предмет`, `#персонаж`, `#тайна`, `#конфликт`, `#реплика`, `#кадр`.

Пользователь должен также уметь создавать свои.

## Не делать в MVP

- EPUB, PDF, MOBI, аудиокниги.
- Синхронизацию iCloud между устройствами.
- Пользовательские аккаунты, сервер или API ИИ.
- Магазин книг, получение книг из сети, DRM.
- Социальные функции, рекомендации, подписки.

## Качество

- Выделение не теряется после перезапуска приложения.
- Экспорт не содержит ничего, кроме выбранного пользователем исследовательского материала.
- Удаление книги требует явного подтверждения и предупреждает о связанных выделениях.
- Пустые, битые или неподдерживаемые FB2-файлы дают понятную ошибку.
- Код не должен притворяться проверенным на iPhone, если Xcode/устройство недоступны.

## Направление дизайна

Спокойная книжная вещь, а не «дашборд»: бумажные оттенки, тёмный древесный режим, крупная типографика, минимум иконок. Главное пространство — текст и заметка пользователя.
